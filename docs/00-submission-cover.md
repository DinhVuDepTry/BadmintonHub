## Tóm tắt đề tài

BadmintonHub là hệ thống web đặt sân cầu lông cho một địa điểm. Hệ thống cho phép khách xem sân và tìm khung giờ trống; Customer đặt, xem và hủy booking; Admin quản lý sân, xác nhận booking và theo dõi dashboard vận hành.

## Công nghệ

- ASP.NET Core MVC/Razor Pages, .NET 8.
- Entity Framework Core và MySQL.
- ASP.NET Identity, Cookie Authentication và RBAC.
- REST API và Swagger.
- Docker, health check, rate limiting và background worker.

## Phạm vi hiện tại

Bao gồm authentication, hồ sơ tài khoản, availability search, court management, booking lifecycle, Admin dashboard, API, security design và kiểm thử service.

Không bao gồm payment, chat, review, mobile app, multi-venue ownership và CourtOwner vì không nằm trong phạm vi MVP đã chọn.
